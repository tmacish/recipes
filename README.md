# Recipes

Recipes from Tommy Mac's kitchen. Some are my own, some were handed down, all built from scratch with no packets.

## About

Every recipe here is made from scratch rather than a package, and heat is generally kept adjustable so the table gets a mild version and anyone who wants more can add it at the plate. A few carry names from an ongoing tabletop campaign, and a few were passed down from family. The flavor notes come along for the ride.
